# 책갈피

하루 한 줄씩 독서 기록을 남기는 서비스 소개 페이지입니다.

배포 주소: https://rlarudgh.github.io/scu-uiux/

## 서비스 소개

- 사용자: 책을 꾸준히 읽고 싶은 20~30대 독서 초보자
- 서비스 목적: 독서 목표를 정하고 짧은 기록을 남기면서 독서 습관을 만들 수 있게 돕는다
- 핵심 행동: 독서 목표 등록
- 완료 조건: 책 제목, 독서 주기, 하루 목표 분량을 정하고 확인 화면에서 "목표 등록"을 누르면 완료

## 사용자 흐름

시작 → 책 입력 → 목표 선택 → 확인 → 완료

1. 시작: "목표 만들기 시작" 버튼을 누른다
2. 책 입력: 책 제목(필수), 저자(선택)를 입력한다
3. 목표 선택: 독서 주기(필수), 하루 목표 분량(필수), 알림 여부(선택)를 고른다
4. 확인: 입력한 내용을 확인하고, 필요하면 "수정"으로 돌아가서 고친다
5. 완료: 등록 완료 표시가 나오고, "첫 기록 남기러 가기" 또는 "다시 시작"을 누를 수 있다

## 인터랙션 시나리오

| 행동                     | 이벤트 | 조건             | 화면 반응                                         | 다음 상태           |
| ------------------------ | ------ | ---------------- | ------------------------------------------------- | ------------------- |
| 시작 버튼 클릭           | click  | -                | 책 입력 화면 표시                                 | 책 입력             |
| 제목 없이 다음 클릭      | click  | 제목이 비어 있음 | 입력창 빨간 테두리, "책 제목을 입력해주세요" 안내 | 책 입력 유지        |
| 제목 입력                | input  | 1자 이상         | 오류 표시 사라짐                                  | 책 입력             |
| 주기·분량 없이 다음 클릭 | click  | 선택 안 함       | 항목별 안내 문구 표시                             | 목표 선택 유지      |
| 주기·분량 선택           | change | 선택함           | 선택한 항목 강조, 오류 사라짐                     | 목표 선택           |
| 이전 클릭                | click  | -                | 이전 화면으로 이동, 입력값 유지                   | 이전 단계           |

| 목표 등록 클릭           | submit | 필수값 모두 입력 | 완료 배지 표시, 진행 단계 모두 완료               | 완료                |
| 첫 기록 남기러 가기 클릭 | click  | 완료 상태        | 한 줄 기록 탭으로 이동, 책 제목 자동 입력         | 기록 작성           |
| 다시 시작 클릭           | click  | -                | 입력값, 선택, 오류, 진행 상태 초기화              | 시작                |

## 기존 기능

- 주요 기능 탭 3개 (한 줄 기록 / 독서 캘린더 / 완독 목록): 클릭하면 선택한 탭만 보이고 탭 색이 바뀜
- 한 줄 감상 입력(input): 글자 수 표시, 40자부터 주황색, 50자 넘으면 빨간색 + 기록 버튼 비활성화
- 읽기 상태 선택(change): 상태 문구, 배지 색, 버튼 문구가 같이 바뀜
- 기록하기(click): 기록 목록에 추가되고 캘린더 오늘 칸이 초록색으로 바뀜, 완독이면 완독 목록에도 추가
- 이메일 알림 신청: 빈 값이면 버튼 비활성화, 형식이 틀리면 오류 문구, 신청하면 완료 문구

## 테스트 결과

크롬에서 화면 너비 1100px, 768px, 390px로 확인했습니다.

| 테스트                              | 1100px | 768px | 390px |
| ----------------------------------- | ------ | ----- | ----- |
| 화면 잘림 / 가로 스크롤 없음        | O      | O     | O     |
| 필수값 없으면 다음 단계로 안 넘어감 | O      | O     | O     |
| 이전으로 돌아가도 입력값 유지       | O      | O     | O     |
| 수정한 값이 확인 화면에 반영됨      | O      | O     | O     |
| 완료 표시, 다시 시작 시 초기화      | O      | O     | O     |
| 탭 전환, 한 줄 기록, 이메일 신청    | O      | O     | O     |

- 768px 이하에서는 버튼이 가로로 꽉 차게 바뀝니다. `box-sizing: border-box`를 넣어서 버튼이 폼 밖으로 나가지 않게 수정했습니다.
- 390px에서는 진행 단계 이름을 숨기고 숫자만 보이게 했습니다.
