# 책갈피

하루 한 줄씩 독서 기록을 남기는 서비스 소개 페이지입니다.

배포 주소: https://rlarudgh.github.io/scu-uiux/

## 서비스 소개

- 사용자: 책을 꾸준히 읽고 싶은 20~30대 독서 초보자
- 목적: 독서 목표를 정하고 짧은 기록을 남기며 독서 습관 만들기
- 핵심 행동: 독서 목표 등록

## 사용자 흐름 (7주차)

시작 → 책 입력(검색 또는 직접 입력) → 목표 선택 → 확인 → 완료

- 필수값(제목, 주기, 분량)이 비면 항목별 오류 안내, 다음 단계로 못 넘어감
- 이전/수정으로 돌아가도 입력값 유지, 다시 시작하면 전체 초기화
- 완료 후 "첫 기록 남기러 가기"로 한 줄 기록 탭에 책 제목 자동 입력

## 중간고사 추가 기능: 책 검색으로 고르기

2단계 "책 입력"(흐름 중간)에 **책 검색 → 결과에서 선택** 경로를 추가했습니다. 고른 책의 쪽수가 확인 화면과 완료 화면의 완독 예상일에 반영됩니다.

| 사용자 행동      | 조건                 | 성공 반응                                    | 다른 분기                                                    | 다음 행동             |
| ---------------- | -------------------- | -------------------------------------------- | ------------------------------------------------------------ | --------------------- |
| 검색 (클릭/Enter) | 공백 제외 1자 이상   | "검색 결과 N권" + 결과 카드                  | 빈 값: 오류 문구 / 결과 없음: [다른 검색어로 찾기] [직접 입력하기] | 책 선택 / 재검색      |
| 이 책 선택       | -                    | 제목·저자 자동 입력, 카드 강조, 선택한 책 표시 | 선택 취소: 제목·저자 비움 / 제목 직접 수정: 선택 해제        | 다음                  |
| 목표 등록        | 검색한 책 + 쪽 단위 목표 | "264쪽 … 약 14일 만에 완독" 표시          | 분 단위 목표나 직접 입력한 책: 문구 없음                     | 첫 기록 남기러 가기   |

- 이전/수정으로 돌아오면 검색 결과·선택 유지, 다시 시작하면 초기화

## 테스트 결과

크롬에서 직접 조작해 확인했습니다.

| 경로      | 시험 내용                                                    | 결과 |
| --------- | ------------------------------------------------------------ | ---- |
| 정상      | "아몬" 검색 → 선택 → 매일·20쪽 등록 → "(264쪽)", "약 14일" 표시 | O    |
| 오류      | 빈 검색어 → 오류 문구, 입력하면 사라짐                       | O    |
| 결과 없음 | "해리포터" → 안내 + 직접 입력/재검색 버튼 동작               | O    |
| 취소·수정 | 선택 취소, 선택 후 제목 수정 → 선택 해제                      | O    |
| 이전      | 3단계·확인 화면에서 돌아와도 검색 결과·선택 유지             | O    |
| 다시 시작 | 검색어·결과·선택 모두 초기화                                 | O    |
| 7주차     | 직접 입력 흐름, 탭 전환, 한 줄 기록, 이메일 신청 그대로 동작 | O    |

1100px / 768px / 390px 모두 가로 스크롤, 버튼·입력창 잘림이나 겹침 없음. 768px 이하에서는 버튼을 세로로 꽉 차게, 390px에서는 결과 카드의 선택 버튼을 책 정보 아래로 배치했습니다.
