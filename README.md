# 책갈피

하루 한 줄씩 독서 기록을 남기는 서비스 소개 페이지입니다.

배포 주소: https://rlarudgh.github.io/scu-uiux/

## 서비스 소개

- 사용자: 책을 꾸준히 읽고 싶은 20~30대 독서 초보자
- 목적: 독서 목표를 정하고 짧은 기록을 남기며 독서 습관 만들기
- 핵심 행동: 독서 목표 등록

## 사용자 흐름 (7주차)

시작 → 책 입력(검색 또는 직접 입력) → 목표 선택 → 확인 → 완료

- 필수값(제목, 주기, 분량)이 비면 항목별 오류 안내, 다음 단계로 못 넘어감
- 이전/수정으로 돌아가도 입력값 유지, 다시 시작하면 전체 초기화
- 완료 후 "첫 기록 남기러 가기"로 한 줄 기록 탭에 책 제목 자동 입력

## 9주차: 메뉴 이동과 목록 탐색

### 추가·수정한 기능

- 주요 메뉴: `nav > ul > li > a` 구조로 바꾸고, 목적지를 알 수 있게 메뉴 이름 변경
- 현재 위치 표시: 현재 섹션 메뉴에만 `aria-current="location"`과 `is-current`(채운 배경·굵게·밑줄) 적용, 나머지 메뉴에서는 제거
  - 메뉴 클릭·뒤로 가기(`hashchange`), 새로고침(`load`), 직접 스크롤(`scroll`) 모두 실제 화면 위치로 다시 계산
- 한 줄 기록 필터: 읽기 상태로 거르기. 선택 버튼 표시(✓·채운 배경), `aria-pressed`, 목록, 개수 문구가 함께 바뀜
- 모바일 메뉴(768px 이하): "메뉴 열기" 버튼으로 펼치고 접기. 메뉴 표시, 버튼 문구(열기/닫기), `aria-expanded`가 함께 바뀜. 메뉴를 고르면 이동 후 닫히고, Esc로도 닫힘

### 메뉴별 목적지

| 메뉴             | 이동 위치   | 내용                                        |
| ---------------- | ----------- | ------------------------------------------- |
| 서비스 소개      | `#intro`    | 책갈피 서비스 설명                          |
| 독서 기록하기    | `#features` | 한 줄 기록 작성·필터, 독서 캘린더, 완독 목록 |
| 이용 방법        | `#howto`    | 이용 순서 3단계                             |
| 독서 목표 만들기 | `#goal`     | 5단계 목표 등록 폼                          |
| 오픈 알림 신청   | `#start`    | 이메일 알림 신청 폼                         |

### 필터 기준 (한 줄 기록 목록의 읽기 상태)

| 필터      | 보여주는 기록         |
| --------- | --------------------- |
| 전체      | 모든 기록             |
| 읽는 중   | 상태가 "읽는 중"      |
| 완독      | 상태가 "완독"         |
| 잠시 멈춤 | 상태가 "잠시 멈춤"    |

- 개수 안내: `기록 3개를 모두 보고 있어요.` / `전체 기록 3개 중 '완독' 1개를 보고 있어요.`
- 기록이 하나도 없을 때: "아직 남긴 기록이 없어요. 첫 기록을 남겨보세요!"
- 선택한 상태의 기록만 없을 때: "'잠시 멈춤' 상태의 기록이 없어요. 다른 상태를 고르거나 전체 보기를 눌러보세요." + [전체 보기] 버튼

## 8주차: 입력 폼 피드백 (독서 목표 만들기 폼)

### 추가·수정한 기능

- 입력 도움말: 제목·독서 주기·하루 분량·알림 시간 아래에 조건 안내를 넣고 `aria-describedby`로 연결
- 실시간 카운터: 제목을 입력하는 동안 `0 / 30자 · 책 제목을 입력해주세요` → `3 / 30자 · ✓ 조건 충족`. 색과 문구를 함께 바꿈
- 조건부 입력: "알림 받기"를 체크하면 알림 시간·알림 방법 영역이 나타남. 체크를 풀면 영역이 숨겨지고 안쪽 입력이 `disabled`로 바뀌며 오류도 사라짐
- 제출 처리: 4단계 "목표 등록"을 누르면 버튼이 비활성화되고 "등록 중…"과 "목표를 저장하고 있어요…"가 표시됨 → localStorage(`bookmark-goals`)에 저장
  - 성공: 완료 화면으로 이동
  - 실패: 4단계에 그대로 남아 입력값이 유지되고, 원인과 해결 방법을 오류 문구로 안내함. 버튼은 "다시 시도"로 바뀜

### 입력 조건

| 항목      | 조건                       | 오류 문구                                |
| --------- | -------------------------- | ---------------------------------------- |
| 책 제목   | 필수, 공백 제외 1~30자     | 책 제목을 입력해주세요. (1~30자)         |
| 독서 주기 | 필수, 하나 선택            | 독서 주기를 하나 선택해주세요.           |
| 하루 분량 | 필수, 목록에서 선택        | 하루 목표 분량을 목록에서 골라주세요.    |
| 알림 시간 | 알림 받기를 체크했을 때만 필수 | 알림 시간을 선택해주세요. 예: 오후 9:00 |

조건을 충족하지 못하면 다음 단계나 제출로 넘어가지 않고, 첫 번째 오류 항목으로 포커스가 이동하며 "필수 항목 N개를 확인해주세요"를 표시합니다. 값을 고치면 해당 오류는 바로 사라집니다.

### 실패 처리 (`script.js`)

| 실패 조건                                      | 코드 위치                       | 안내                                                 |
| ---------------------------------------------- | ------------------------------- | ---------------------------------------------------- |
| 같은 책 제목의 목표가 이미 저장되어 있음        | `saveGoal` → `Error("duplicate")` | "이미 『제목』 목표가 등록되어 있어요. 책 '수정'을 눌러…" |
| localStorage 쓰기 오류 (용량 초과, 저장 차단)   | `saveGoal`의 try/catch → `Error("storage")` | "목표를 저장하지 못했어요. 입력한 내용은 그대로 있으니…" |

`completeGoal`이 오류를 받아 `SUBMIT_ERRORS`의 문구를 표시하고 버튼을 "다시 시도"로 바꿉니다. 중복 제출은 `goalState.submitting`과 버튼 `disabled`로 막습니다.
같은 제목으로 다시 등록하면 실패를 재현할 수 있습니다.

## 중간고사 추가 기능: 책 검색으로 고르기

2단계 "책 입력"(흐름 중간)에 **책 검색 → 결과에서 선택** 경로를 추가했습니다. 고른 책의 쪽수가 확인 화면과 완료 화면의 완독 예상일에 반영됩니다.

| 사용자 행동      | 조건                 | 성공 반응                                    | 다른 분기                                                    | 다음 행동             |
| ---------------- | -------------------- | -------------------------------------------- | ------------------------------------------------------------ | --------------------- |
| 검색 (클릭/Enter) | 공백 제외 1자 이상   | "검색 결과 N권" + 결과 카드                  | 빈 값: 오류 문구 / 결과 없음: [다른 검색어로 찾기] [직접 입력하기] | 책 선택 / 재검색      |
| 이 책 선택       | -                    | 제목·저자 자동 입력, 카드 강조, 선택한 책 표시 | 선택 취소: 제목·저자 비움 / 제목 직접 수정: 선택 해제        | 다음                  |
| 목표 등록        | 검색한 책 + 쪽 단위 목표 | "264쪽 … 약 14일 만에 완독" 표시          | 분 단위 목표나 직접 입력한 책: 문구 없음                     | 첫 기록 남기러 가기   |

- 이전/수정으로 돌아오면 검색 결과·선택 유지, 다시 시작하면 초기화

## 파일 구조

```md
index.html
styles.css
script.js   기능별 주석으로 구분
            1. 이메일 알림 신청  2. 주요 기능 탭  3. 한 줄 기록
            4. 책 검색으로 고르기 (중간고사 추가)  5. 독서 목표 만들기 (8주차 조건부 입력·제출 처리)
            6. 메뉴 이동 · 현재 위치 · 모바일 메뉴 (9주차)
```
