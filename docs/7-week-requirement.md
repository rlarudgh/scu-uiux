[과제 요구사항]

1. 자신의 서비스의 주요 사용자, 사용자 목표, 완료할 핵심 행동과 완료 조건을 정합니다.
2. 시작·입력 또는 선택·확인·완료로 이어지는 흐름을 서비스에 맞게 구성합니다. 단계는 다섯 단계 이내로 정합니다.
3. 사용자 행동을 ‘행동 → 이벤트 → 조건 → 화면 반응 → 다음 상태’로 정리하고 실제 화면에 구현합니다.
4. 필수 입력이나 선택이 누락되면 다음 단계로 넘어가지 않도록 하고, 수정 방법을 화면에 안내합니다.
5. 이전 단계로 돌아가도 입력·선택한 값이 유지되고, 수정한 값이 확인 화면에 반영되도록 구현합니다.
6. 완료 여부를 명확하게 표시하고, 다시 시작하면 해당 흐름의 입력·선택·오류·진행 상태가 초기화되도록 구현합니다.
7. 모바일에서도 화면이 잘리지 않고 조작할 수 있는지 확인합니다.
8. README를 현재 프로젝트 설명으로 갱신합니다. 사용자·서비스 목적·핵심 행동·완료 조건·사용자 흐름·인터랙션 시나리오·테스트 결과·배포 주소를 포함합니다.

기존 서비스의 기능을 유지하면서 새로운 흐름을 연결하세요. 수업에서 사용한 발표 훈련이나 공방 예약 예제를 그대로 제출하지 않고, 본인의 서비스에 적용합니다.
