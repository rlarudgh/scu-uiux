# 13주차 사용자 테스트 기록 (양식 A~E)

> `[ ]`는 테스트를 진행하면서 채울 칸입니다. 참여자는 코드(P01, P02 …)로만 적습니다.

## 양식 A · 테스트 계획서 · 과업지

- 서비스·주로 사용할 사람: 책갈피(하루 한 줄 독서 기록) · 책을 꾸준히 읽고 싶은 20~30대 독서 초보자
- 확인할 질문: 새로고침 뒤 복구 안내를 알아차리고, 같은 내용을 다시 입력하지 않고 목표를 등록하는가? 검색에 없는 책도 직접 입력해서 알림까지 설정할 수 있는가?
- 테스트 버전·배포 주소: [커밋 해시] · https://rlarudgh.github.io/scu-uiux/#goal
- 참여자 코드·서비스나 코드를 본 경험: P01 · [처음 봄 / 화면만 본 적 있음 / 코드도 봄]
- 실제 참여 인원·진행자·기록자: [ ]명 · 진행자 [ ] · 기록자 [ ]
- 기기·브라우저·화면 너비: [예: 노트북 · Chrome · 1440px / 휴대폰 · Safari · 390px]
- 과업별 제한 시간·도움을 줄 기준: 과업당 5분. 30초 이상 멈추면 "지금 무엇을 찾고 있나요?"라고만 묻고, 그래도 진행하지 못하면 위치를 알려 주고 '도움'으로 기록

### 과업 T1 (대표 과업 · 새로고침 뒤 이어서 등록)

- 참여자에게 읽을 문장: "『아몬드』를 매일 20쪽씩 읽는 목표를 만들다가 마지막 확인 화면에서 화면이 새로고침됐어요. 하던 내용으로 목표를 마저 등록해 주세요."
- 시작 화면·입력값 (진행자가 준비): 독서 목표 만들기에서 검색 "아몬드" → 『아몬드』 선택 → 매일 / 20쪽 / 알림 받기 21:00 앱 푸시 → 4단계(확인) 화면에서 새로고침한 상태. 시작 전 `bookmark-goals`(등록 목록)는 비워 둠
- 진행자용 완료 기준: 같은 값을 다시 입력하지 않고 '목표 등록' → 5단계 "목표 등록 완료" 화면이 보임

### 과업 T2 (다른 경로 · 검색에 없는 책 직접 입력 + 알림 설정)

- 참여자에게 읽을 문장: "검색해도 나오지 않는 『불편한 편의점』(김호연)을 주말마다 30분씩 읽고 싶어요. 오후 9시에 이메일로 알림을 받도록 목표를 등록해 주세요."
- 시작 화면·입력값: 독서 목표 만들기 1단계 빈 화면 (sessionStorage 임시값 없음, 새 탭)
- 진행자용 완료 기준: 4단계 요약이 "불편한 편의점 · 김호연 / 주말만 / 30분 / 받기 · 21:00 · 이메일"이고 등록 완료 화면이 보임

## 양식 B · 진행 안내문 (참여자에게 읽기)

> 오늘은 이 웹페이지가 쓰기 쉬운지 알아보려고 합니다.
> 화면을 쓰면서 무엇을 하려는지, 어떤 결과를 예상하는지 말해 주세요.
> 막히면 말씀해 주세요. 원하면 언제든 멈출 수 있습니다.
> 기록에는 이름 대신 참여자 번호를 쓰겠습니다.
> (사진을 찍는다면) 얼굴·이름이 보이지 않게 화면과 손만 한 장 찍어 과제 기록에 올려도 될지 여쭙겠습니다.

1. 과업마다 위의 시작 화면과 입력값을 똑같이 준비합니다.
2. 과업 문장을 읽고 시작 시각을 적습니다. 클릭 순서·버튼 위치는 알려 주지 않습니다.
3. 클릭, 발언, 도움 요청이 나온 시각을 적습니다.
4. 완료했거나 5분이 지나거나 참여자가 멈추면 끝내고 양식 D 질문을 합니다.
