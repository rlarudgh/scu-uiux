지금까지 제작한 본인의 서비스 웹페이지에 입력 폼을 추가하거나 개선하세요.
사용자가 무엇을 입력해야 하는지 이해하고, 잘못된 입력을 수정하여 제출을 완료할 수 있도록 구현합니다.

[과제 요구사항]

1. 본인의 서비스에 맞는 입력 폼 구성

- 수업 예제인 발표 훈련 서비스를 그대로 사용하지 않고, 본인이 기획한 서비스에 적용합니다.
- 예약, 신청, 게시글 작성, 상품 등록 등 서비스의 주요 행동과 연결되는 폼을 구성합니다.
- 텍스트 입력과 선택 요소를 포함하여 입력 항목을 두 가지 이상 구성합니다.
- 각 입력 요소에 label을 연결하고, 필요한 입력 조건을 도움말로 안내합니다.

2. 선택에 따른 조건부 입력 구현

- 체크박스, 라디오 버튼 등의 선택에 따라 추가 입력 영역이 나타나거나 사라지도록 구현합니다.
- 숨겨진 영역의 입력 요소는 disabled로 비활성화하고, 다시 표시되면 사용할 수 있도록 처리합니다.

3. 입력 상태와 피드백 표시

- 필수 입력, 최소 글자 수 등 서비스에 필요한 검증 조건을 한 가지 이상 적용합니다.
- 입력하는 동안 글자 수나 조건 충족 여부가 화면에 표시되도록 구현합니다.
- 조건을 충족하지 못하면 문제와 수정 방법을 알려주는 오류 문구를 표시하고, 올바르게 수정하면 오류가 해제되도록 합니다.
- 상태는 색상뿐 아니라 문구로도 구분합니다.

4. 폼 제출과 결과 처리

- form의 submit 이벤트로 제출을 처리합니다.
- 조건을 충족하지 못하면 제출을 막고, 수정이 필요한 항목을 안내합니다.
- 제출 중에는 진행 문구를 표시하고 제출 버튼을 비활성화하여 중복 제출을 막습니다.
- 성공하면 완료 안내를 표시하고, 실패하면 입력 내용을 유지한 상태에서 다시 시도할 수 있도록 처리합니다.
- 서버 연동은 필요하지 않습니다. 수업에서 다룬 브라우저 저장 기능을 활용해도 됩니다.

5. 동작 확인 및 README 작성

- 브라우저에서 빈 값 제출, 잘못된 값 입력, 오류 수정, 조건부 영역 변경, 정상 제출을 직접 확인합니다.
- 다시 작성 기능이 있다면 입력값과 안내 문구, 버튼 상태가 함께 초기화되는지 확인합니다.
- README에 이번 주 추가·수정한 기능, 입력 조건, 확인 순서를 간단히 작성합니다. 실패 처리는 해당 조건과 코드 위치를 설명해도 됩니다.
