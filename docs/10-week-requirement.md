지금까지 제작한 본인의 서비스 웹페이지에서 메뉴 이동과 목록 탐색 기능을 개선하세요. 사용자가 현재 위치를 파악하고, 필요한 정보를 골라 보며, 모바일에서도 주요 기능을 이용할 수 있도록 구현합니다.

[과제 요구사항]

1. 서비스에 맞는 메뉴 구성

- 수업 예제인 발표 훈련 서비스를 그대로 사용하지 않고, 본인이 기획한 서비스에 적용합니다.
- 주요 메뉴를 세 가지 이상 구성하고, 각 메뉴가 해당 영역이나 화면으로 이동하도록 연결합니다.
- 메뉴 이름은 사용자가 목적지를 예상할 수 있도록 작성합니다.
- 주요 메뉴는 nav와 ul·li 구조로 구성합니다.

2. 현재 위치 표시

- 현재 위치에 해당하는 메뉴가 다른 메뉴와 시각적으로 구분되도록 구현합니다.
- 현재 메뉴에 aria-current를 적용하고, 다른 메뉴에서는 제거합니다.
- 메뉴 이동, 새로고침, 브라우저 뒤로 가기 이후에도 현재 위치 표시가 실제 화면과 일치하도록 합니다.

3. 목록 필터와 결과 안내

- 본인 서비스의 목록에 카테고리, 진행 상태 등 의미 있는 필터를 적용합니다.
- ‘전체’를 포함하여 필터를 세 가지 이상 구성합니다.
- 필터 선택 시 버튼의 선택 표시와 실제 목록 내용이 함께 변경되도록 합니다. 버튼의 선택 상태는 aria-pressed에도 반영합니다.
- 현재 표시되는 항목 수를 안내하고, 결과가 없으면 빈 화면 대신 안내 문구를 표시합니다.
- 전체 목록이 없는 경우와 선택한 조건에 맞는 결과만 없는 경우를 구분하여 안내합니다.

4. 모바일 메뉴 구현

- 좁은 화면에서는 메뉴 열기·닫기 버튼을 통해 주요 메뉴를 펼치거나 접을 수 있도록 합니다.
- 메뉴의 실제 표시 상태, 버튼 문구, aria-expanded 값이 함께 변경되도록 합니다.
- 메뉴에서 목적지를 선택하면 해당 위치로 이동하고 펼쳐진 메뉴가 닫히도록 합니다.
- 넓은 화면에서는 주요 메뉴가 정상적으로 표시되고, 좁은 화면에서는 버튼과 콘텐츠가 겹치지 않도록 합니다.

5. 전체 흐름 확인 및 README 작성

- 메뉴 이동 → 주요 기능 이용 → 결과 목록 확인 → 필터 선택의 흐름을 직접 확인합니다.
- PC와 모바일 화면에서 모두 확인하고, 기존 입력·저장·상세 보기 등의 기능도 정상적으로 작동하도록 유지합니다.
- README에 이번 주 추가·수정한 기능, 메뉴별 목적지, 필터 기준, 기능을 확인할 수 있는 조작 순서를 간단히 작성합니다.
